## Highlights

* Gravimetry overestimates oil content at high salinity, reaching deviations of up to **60% at 100 g/L NaCl**.

* Spectrophotometry maintains consistent accuracy over a broad salinity range of **0–100 g/L NaCl**.

* Three-way ANOVA identified a significant interaction between measurement technique, salinity, and TOG concentration.

* The spectrophotometric methods presented limits of detection between **11.1 and 13.7 ppm**.

* The corresponding limits of quantification ranged from **33.5 to 41.6 ppm** in water.

* Spectrophotometry was less susceptible to interference from dissolved salts than gravimetry.

* Gravimetry remained suitable for low-salinity samples but required additional consideration when applied to highly saline produced water.

## Python Scripts

The `codes/` folder contains all source code used in the statistical evaluation of the experimental results.

The experimental data are stored directly within the corresponding Python files. Each script is associated with a specific experimental point, oil concentration, salinity condition, measurement technique, or statistical procedure.

The scripts may include the following analyses:

* Experimental data organization and preprocessing
* Calculation of mean values and standard deviations
* Accuracy and relative error calculation
* Gravimetric and spectrophotometric method comparison
* Calibration-curve fitting
* Coefficient of determination calculation
* Limit of detection calculation
* Limit of quantification calculation
* Analysis of variance
* Effect-size estimation
* Residual analysis
* Normality and homoscedasticity evaluation
* Statistical figure generation

Because the experimental values are embedded in the Python scripts, no separate `.csv` dataset is required to reproduce the analyses.

## Experimental Conditions

The experimental design considered the influence of three main factors:

| Factor                    | Evaluated conditions                          |
| ------------------------- | ----------------------------------------------|
| Measurement technique     | Gravimetry, spectrophotometry and Colorimetry |
| NaCl concentration        | 0–100 g/L                                     |
| Nominal TOG concentration | 50, 300, 500, 800, and 1000 ppm               |

Additional tests using an oil-soluble pigment were performed to evaluate the adaptability and sensitivity of the spectrophotometric method.

The synthetic samples were prepared to represent produced-water conditions while maintaining controlled oil and salinity concentrations.

## Reproducibility

To reproduce the study results:

1. Install the required Python packages.
2. Open the `codes/` directory.
3. Review the experimental values embedded in each script.
4. Run the scripts associated with each experimental condition.
5. Run the scripts responsible for the combined statistical analyses.
6. Compare the generated outputs with the files available in the `figs/` directory.

The numerical statistical results should remain consistent when equivalent package versions and input data are used.
